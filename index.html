안녕하세요.
저는 꾸준함과 성실함을 바탕으로 새로운 도전에 빠르게 적응하며 성장해온 퍼블리싱 지망자입니다.

예체능 계열로 진학했지만 진로에 대해 깊이 고민하면서 실용성과 흥미를 모두 충족할 수 있는 IT 분야를 선택하게 되었고, 장안대학교 소프트웨어융합과에 입학해 퍼블리싱에 집중하게 되었습니다. 특히 퍼블리싱은 노력한 만큼 결과가 눈앞에 바로 나타나는 점이 매력적이었고, 세밀한 작업을 좋아하는 제 성향과도 잘 맞았습니다.

모바일웍스에서 3개월간 인턴으로 근무하며 나라사랑카드 대응개발 프로젝트의 퍼블리싱 업무를 담당했습니다. 피그마 시안을 기반으로 디자이너와 협업하여 카드 혜택·실적, 재발급, ARS 사후출금동의, 카드 신청·본인인증, 신청서 작성(간소화) 등 다양한 화면을 구현했습니다. 이 경험을 통해 실제 서비스 환경에서의 퍼블리싱 워크플로우, 협업 프로세스, 그리고 디자인·개발 간 소통의 중요성을 깊이 이해할 수 있었습니다.

HTML5, CSS3, Bootstrap을 활용한 퍼블리싱 역량을 갖추고 있으며, 구름 플랫폼을 통해 Git부터 React까지 다양한 기술을 학습하며 개발 감각과 협업 능력을 함께 키워왔습니다. 활동적인 성격 덕분에 체력 관리에 익숙해 장기 프로젝트에서도 지속적인 집중력과 끈기를 유지할 수 있는 점도 제 강점입니다.

비록 출발은 남들보다 늦었지만, 저는 꾸준함을 무기로 부족한 부분을 하나씩 채워가며 성장하고 있습니다. 앞으로도 팀의 목표 달성과 서비스 품질 향상을 위해 적극적으로 배우고 기여하는 퍼블리셔가 되겠습니다.

개요

이 프로젝트는 MZ세대 대상으로 한 맞춤형 향수 추천 쇼핑몰 입니다.
이 프로젝트의 목표는 개성과 취향을 중시하는 MZ 세대가
자신의 스타일과 성격에 맞는 향수를 쉽게 찾을 수 있도록 돕는 것입니다.

프로젝트 목표

▶ 맞춤형 향수 추천을 통해 사용자의 선택의 어려움을 줄이기
▶ 향수 입문 자들이 쉽게 접근할 수 있는 환경 조성
▶ MZ 세대를 타겟 으로 한 효과적인 마케팅 전략 수립

주요 기능

▶ 옷 스타일에 맞는 향수 추천 테스트
  ▪ 사용자가 원하는 패션 스타일을 3가지 선택하면
해당 스타일에 어울리는 향수를 추천
▶ 향수 MBTI 테스트
  ▪ MBTI 성격 유형과 유사한 테스트를 통해 사용자의 성격과
    취향을 분석, 맞춤형 향수 추천

useEffect(() => {
    const exchangeToken = async () => {
        try {
            const response = await fetch("https://fit-conference.shop/api/v1/auth/token-exchange", {
            method: "POST",
            headers: { "Content-Type": "application/json" },
              credentials: "include",
            });
            
            if (response.ok) {
              let token = response.headers.get("Authorization");
              if (token?.startsWith("Bearer ")) token = token.substring(7);
              localStorage.setItem("access-token", token);
            
              const userInfo = await axios.get("https://fit-conference.shop/api/v1/users/account", {
                headers: { Authorization: `Bearer ${token}` },
              });
            
              dispatch(loginSuccess({ user: userInfo.data.response, token }));
              navigate("/mypage");
            }
          } catch (error) {
            console.error("Token exchange failed:", error);
          }
        };
            
        exchangeToken();
      }, []);
